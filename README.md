# ELE323 Individual Project Code

This repository contains the implementation developed for the ELE323 individual project on microgrid energy scheduling.

## Repository structure
- `models/convex/`: convex baseline model
- `models/regularised/`: regularised convex model
- `models/mip/`: mixed-integer model
- `experiments/exp_01_synthetic_baseline/`: synthetic baseline experiments
- `experiments/exp_02_parameter_sweep/`: parameter sweep experiments
- `experiments/exp_03_uk_validation/`: UK-data-based validation
- `scripts/`: MATLAB scripts for data generation, result processing, and figure generation

## Software used
- AMPL
- Gurobi
- MATLAB

## Purpose
This repository is provided to support the dissertation submission and the reproducibility of the reported results.
